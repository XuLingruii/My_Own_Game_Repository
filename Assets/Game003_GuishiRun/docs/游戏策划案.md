# 《夜渡》首版游戏策划案

> 本文是 Game003 后续开发的策划基准。开发任务、实现和验收以本文为参考，只有用户明确要求修改策划案时才更新本文。文中标记为「暂定」或「待定」的内容可在对应阶段验证，涉及玩法或范围的变更先与用户确认。

**《夜渡》是一款 PC 端 2D 横版动作游戏。** 玩家扮演一名带着随身物件叛逃的鬼差，从街面、屋顶或暗巷穿过戒备中的鬼市。首版做一段连续关卡，把跑跳、近战、潜行和收服小弟串进同一次通关。

## 1. 故事与氛围

开场，鬼差站在鬼市入口，说一句「我得穿过这片鬼市。」随后立即交给玩家操作。主角已经带着要带走的物件，物件是什么、叛逃的缘由留给后续剧情。士兵在前方巡逻搜捕，居民照常摆摊、闲聊。玩家可以直接赶路，也可以停下来听几句，了解前方哪里有人巡逻、哪架梯子能上屋顶。

场景走中式志怪风格。街面是灯笼、摊棚和鬼影，屋顶有连片瓦檐，暗巷靠墙壁、箱堆和局部灯光分出藏身处。打斗强调清晰的横劈、竖砍和有辨识度的刀光剑气。

## 2. 鬼市关卡

| 路段 | 玩家看到什么 | 玩家可以怎么过 |
|---|---|---|
| **进入鬼市** | 灯笼下有摊贩和闲聊的居民，街上有矮摊位和一处断路。第一名巡逻士兵出现在前方。 | 停下对话或偷听，也可以跳过摊位、二段跳跨过断路，直接进入巡逻区。 |
| **中段分流** | 岔口能看到正前方的巡逻士兵、通向屋顶的梯子，以及通往下层暗巷的入口。 | **街面**可以冲刺穿过小怪接连斩。**屋顶**以攀爬和跑跳为主。**暗巷**可以下蹲藏身，等士兵走过后绕行，或趁它背对时处决。屋顶或暗巷可间歇出现孤魂野鬼。 |
| **穿过鬼市** | 三条路在牌楼前汇合。最后一截屋檐下面是窄巷，门外能看到黄泉路。 | 可以处理最后的巡逻士兵，也可以沿屋檐跳过窄巷，从牌楼离开。穿过牌楼即通关。 |

鬼市内允许回头，路线之间没有加载画面。首版可以用一张连续场景实现，把街面、屋顶和暗巷组织成独立段落。地图扩展后，再把连续场景拆成可以提前加载和按需卸载的区段。黄泉、奈何桥、阎罗殿是后续场景候选，首版做到鬼市出口。

## 3. 操作、战斗与潜行

| 输入 | 行为 |
|---|---|
| `A/D` | 左右移动 |
| `Space` | 跳跃，空中再按一次触发二段跳 |
| `Shift` | 冲刺，可以穿过普通敌人，结束时可以接普攻 |
| `F` | 挂上梯子或绳索 |
| `W/S` | 攀爬时向上或向下，地面上按 `S` 下蹲 |
| `E` | 敌人背对主角且进入近身范围时，触发处决 |
| 待定 | 普攻、主动对话和后续技能的按键 |

**普攻**首版做横劈、竖砍两段，分别配刀光和命中特效。冲刺、普攻和处决各有自己的用途。冲刺用于越过敌人并调整位置，普攻用于正面交战，处决用于处理落单的背身士兵。

**潜行**首版暂定采用视线规则。玩家需要先利用转角或遮挡脱离视线，再在指定点下蹲藏身。士兵会到最后看见主角的位置附近短暂搜查，之后恢复巡逻。游戏只在主角距离和朝向满足条件时显示 `E` 提示。玩家也可以等士兵离开，直接通过暗巷。

## 4. 居民、士兵与孤魂野鬼

| 类型 | 行为与规则 |
|---|---|
| **鬼市居民** | 可主动对话，也可靠近偷听。居民和主角互相无法造成伤害。居民的对话用于表现鬼市日常，也可以提示路线。 |
| **巡逻士兵** | 沿固定路线巡逻，发现主角时在附近追击或拦截，丢失目标后短暂搜查。可攻击、可在满足条件时处决、无法对话或交互。击败后掉落物品。 |
| **孤魂野鬼** | 在指定区域间歇出现。击败后掉落物品，并有概率触发收服。暂定收服判定在掉落后进行，因此收服成功也保留掉落。 |
| **收服的小弟** | 默认跟随主角。附近出现敌人时自动锁定并攻击一名敌人，目标消失或主角离开后回到身边。居民不进入索敌范围。 |

首版暂定**同一时间最多跟随一名小弟**。已有小弟时，击败野鬼仍会掉落物品。小弟离主角过远或卡在地形时，可以在镜头外回到主角附近，避免一只小弟卡在梯子下，中断整条路线。收服概率、掉落内容和小弟伤害留给灰盒试玩后调整。

## 5. 开发顺序与验收

在 `Main_Game_603` 的 Game003 下开发。先沿用 603 的内置渲染管线，用 Unity 粒子系统实现刀光、命中和消散效果。后续需要 URP 2D 灯光时，再评估对同项目其他游戏的影响。

| 阶段 | 交付与验收 |
|---|---|
| **1. 灰盒与生命周期** | 用占位图形搭出三段路线。能移动、二段跳、冲刺、攀爬、通关和重开。连续重开后，角色状态、敌人和掉落都能正确复位。 |
| **2. 战斗、潜行和居民** | 跑通冲刺接两段斩击、士兵巡逻与搜查、下蹲藏身、背身处决。居民可交谈和偷听，攻击不会伤害居民。 |
| **3. 野鬼、掉落和小弟** | 验证野鬼击败后正常掉落，收服成功后小弟能跟随，并主动攻击下一名附近敌人。经过岔路、攀爬或重开时，跟随状态正确。 |
| **4. 渲染、对象池与性能** | 加入分层背景、灯笼和粒子。优先复用刀光、命中特效和高频生成的掉落物，用同一段鬼市路线比较复用前后的帧耗时和 `GC Alloc`。 |
| **5. 加载、线程池与热更练习** | 连续地图扩展时验证区段加载。可以用 `.NET` 线程池在后台计算区段刷怪计划，回到主线程放置 Unity 对象。先做一次 Addressables 远程内容更新，让已打包的客户端读到新的掉落配置或特效。技能树和代码热更放到后续。 |

**首版的通关验收**是从鬼市入口出发，三条中段路线都能走到同一牌楼。玩家可以正面打、从屋顶绕，也可以在暗巷里藏身后通过。收服小弟是途中可遇到的奖励，三条路都应在未收服小弟时照常通关。
